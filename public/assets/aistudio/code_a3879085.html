sync_disabled State 1: Graceful Degradation

When OAuth tokens expire or a user elects not to link Google Calendar, the planner preserves full standalone capability. Direct in-context connection keeps activation within the creation flow.

inbox_customize State 2: Unscheduled Guardrail

Google Calendar requires start and end timestamps. In Inbox mode, the UI dynamically disables external sync and transforms the primary call-to-action to "Save to Inbox" to prevent silent sync errors.

verified State 3: 2-Way Sync Assurance

For existing tasks, the drawer provides verifiable telemetry: last synced delta, quick deep-linking to Google's web calendar, and high-contrast status feedback matching brand guidelines.
